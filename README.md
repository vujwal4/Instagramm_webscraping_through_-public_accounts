# Instagramm_webscraping_through_-public_accounts
📌 Overview

This project is a Python-based web scraping tool that extracts publicly available data from Instagram profiles. It is designed for learning and research purposes, focusing on gathering basic profile information from public accounts.

🚀 Features
Scrapes public Instagram profile data
Extracts:
Username
Followers count
Following count
Number of posts
Bio (if available)
Simple and easy-to-use script
Built using Python libraries
🛠️ Tech Stack
Python 🐍
Requests / Selenium / BeautifulSoup (whichever you used)
JSON / Pandas (if applicable)
📂 Project Structure
Instagramm_webscraping_through_-public_accounts/
│── main.py
│── requirements.txt
│── README.md
⚙️ Installation
Clone the repository:
git clone https://github.com/vujwal4/Instagramm_webscraping_through_-public_accounts.git
cd Instagramm_webscraping_through_-public_accounts
Install dependencies:
pip install -r requirements.txt
▶️ Usage

Run the script:

python main.py

Enter the Instagram username when prompted.

⚠️ Limitations
Works only for public accounts
Instagram may block requests after multiple attempts
No support for private profiles
May break if Instagram changes its structure or API
